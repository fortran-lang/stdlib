# Fortran stdlib Specifications (specs)

This is an index/directory of the specifications (specs) for each new module/feature as described in the
[workflow document](../contributing/Workflow.md).

```{contents}
:local:
:depth: 2
```

## Experimental Features & Modules

 - [ansi](./stdlib_ansi.md) - Terminal color and style escape sequences
 - [array](./stdlib_array.md) - Procedures for index manipulation and array handling
 - [ascii](./stdlib_ascii.md) - Procedures for handling ASCII characters
 - [constants](./stdlib_constants.md) - Constants
 - [bitsets](./stdlib_bitsets.md) - Bitset data types and procedures
 - [error](./stdlib_error.md) - Catching and handling errors
 - [state_type](./stdlib_error_state_type.md) - General state and error handling 
 - [hash](./stdlib_hash_procedures.md) - Hashing integer
 vectors or character strings
 - [hashmaps](./stdlib_hashmaps.md) - Hash maps/tables
 - [io](./stdlib_io.md) - Input/output helper & convenience
 - [kinds](./stdlib_kinds.md) - Kind parameters
 - [linalg](./stdlib_linalg.md) - Linear Algebra
 - [linalg_state_type](./stdlib_linalg_state_type.md) - Linear Algebra state and error handling 
 - [logger](./stdlib_logger.md) - Runtime logging system
 - [math](./stdlib_math.md) - General purpose mathematical functions
 - [optval](./stdlib_optval.md) - Fallback value for optional arguments
 - [quadrature](./stdlib_quadrature.md) - Numerical integration
 - [random](./stdlib_random.md) - Probability Distributions random number generator
 - [sorting](./stdlib_sorting.md) - Sorting of rank one arrays
 - [stats](./stdlib_stats.md) - Descriptive Statistics
 - [stats_distributions_uniform](./stdlib_stats_distribution_uniform.md) - Uniform Probability Distribution
 - [stats_distributions_normal](./stdlib_stats_distribution_normal.md) - Normal Probability Distribution
 - [stats_distributions_exponential](./stdlib_stats_distribution_exponential.md) - Exponential Probability Distribution
 - [stats_distributions_beta](./stdlib_stats_distribution_beta.md) - Beta Probability Distribution
 - [stats_distributions_gamma](./stdlib_stats_distribution_gamma.md) - Gamma Probability Distribution
 - [string\_type](./stdlib_string_type.md) - Basic string support
 - [stringlist_type](./stdlib_stringlist_type.md) - 1-Dimensional list of strings
 - [strings](./stdlib_strings.md) - String handling and manipulation routines
 - [system](./stdlib_system.md) - OS and sub-processing routines
 - [version](./stdlib_version.md) - Version information
